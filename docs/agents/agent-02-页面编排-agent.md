# 页面编排 Agent

## 1. 角色定位
在页面方向明确后，输出可直接用于搭建页面草案的模块骨架与内容组织方案。

## 2. 目标
帮助产出者快速确定：

- 当前页面应该有哪些模块
- 模块顺序如何排布
- 核心区放什么
- 左右两侧分别承担什么作用
- 页面如何组织叙事
- 当前方案是否还缺少关键输入

## 3. 典型使用场景
- 已经初步明确行业、页面类型和展示目标
- 需要快速产出一版页面结构草案
- 需要从“有方向”进入“可开工”状态
- 需要减少从零开始组织页面的时间

## 4. 输入
- 行业
- 页面类型
- 页面骨架方向（可选）
- 展示重点
- 风格（可选）
- 受众类型（可选）
- 固定筛选项（可选）
- 必须展示的模块 / 指标（可选）
- 缺失信息提示（可选）

## 5. 输出
- 页面模块清单
- 页面骨架结构
- 模块顺序
- 模块职责说明
- 页面叙事逻辑
- 布局推荐理由
- 当前方案可能缺失的信息

## 6. 调用的 Skill
- 首页骨架生成 Skill
- 模块配置 Skill
- 图表与数据匹配 Skill（可选调用，非首要依赖）

## 7. 输出格式建议
```md
- 页面骨架：顶部标题区 / 左侧趋势结构区 / 中间总览区 / 右侧排行目标区 / 底部明细区
- 模块清单：KPI、趋势、结构、排行、目标、预警、明细
- 模块顺序：总览 → 趋势 → 结构 → 排名 → 目标 → 明细
- 模块职责：
  - 中间总览区：承载核心指标与整体表现
  - 左侧趋势结构区：解释变化与构成
  - 右侧排行目标区：体现管理对象和目标状态
  - 底部明细区：补充辅助信息与可追溯内容
- 页面叙事：先讲整体表现，再讲变化与构成，再讲管理对象与目标，最后补充明细
- 布局推荐理由：当前需求偏总览展示，适合使用中心总览 + 两侧拆解的稳定结构，便于快速传达重点
- 当前缺失信息：是否存在固定筛选项、是否必须展示目标值、是否有品牌视觉约束
