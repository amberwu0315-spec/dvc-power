# 页面方案输出 Agent

## 1. 角色定位
将前面得到的需求理解结果、页面编排结果和模块配置结果，整理成一份可直接用于继续制作页面草案、demo、原型或交给 Codex 执行的方案说明。

## 2. 目标
帮助产出者从“想清楚了”进入“可以继续执行了”。

## 3. 典型使用场景
- 已经明确页面方向与模块结构
- 需要进入设计、AI 出图、原型制作或 Codex 落地阶段
- 需要一份可复制、可传达、可继续执行的说明文本
- 需要减少从思路到执行之间的整理成本

## 4. 输入
- 需求理解结果
- 页面编排结果
- 模块配置结果
- 图表建议结果（可选）
- 当前缺失信息（可选）

## 5. 输出
- 页面方案摘要
- 页面结构说明
- 模块说明清单
- 图表建议清单（可选）
- 当前缺失信息与待确认项
- 默认假设说明（如有）
- 可直接执行的制作说明文本

## 6. 调用的 Skill
- 模板说明生成 Skill
- 图表与数据匹配 Skill（可选调用）
- 背景图提示词 Skill（弱依赖，可选）
- 假数据生成 Skill（弱依赖，可选）

## 7. 输出格式建议
```md
# 页面方案摘要
- 行业：制造业能碳
- 页面类型：总览型页面
- 页面骨架：顶部标题区 / 左侧趋势结构区 / 中间总览区 / 右侧排行目标区 / 底部明细区
- 风格：深色科技能源风（如未明确，可作为建议项）

# 模块清单
- KPI 总览
- 月度趋势
- 排放结构
- 工厂排行
- 目标达成
- 预警列表
- 工厂明细

# 当前缺失信息
- 是否有固定品牌色
- 是否必须展示目标值对比
- 是否有固定筛选维度

# 默认假设
- 默认页面用途偏展示总览
- 默认采用深色稳定风格
- 默认包含工厂与年份筛选

# 制作说明
请基于当前页面结构完成一版制造业能碳总览页面草案。中心突出整体表现，左侧负责趋势与结构解释，右侧负责排行与目标呈现，底部补充明细信息。若品牌规范未提供，先采用专业、稳定、可复用的深色方案。
