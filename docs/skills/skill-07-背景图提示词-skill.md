# 背景图提示词 Skill

## 1. 作用
为背景图或中心视觉生成稳定提示词，用于 AI 出图或素材整理。

## 2. 输入
- 行业
- 风格
- 页面角色

## 3. 输出
- 主提示词
- 负面提示词
- 构图建议
- 元素建议

## 4. 输出格式建议
```md
- 主提示词：深色科技能源风、工业感、能源流动感、数据监控、克制发光、蓝青绿高亮
- 负面提示词：过度赛博、过强装饰、人物主体、卡通感
- 构图建议：中心聚焦，四周留出图表区域
- 元素建议：工业线条、能流网络、科技网格、轻量地形或园区暗示
```

## 5. 规则（v1）
1. 提示词要服务于页面，不是独立美术作品。
2. 中心视觉不能过强，避免压制图表与信息层。
3. 输出必须包含负面提示词，帮助控制失控风格。
4. 构图需考虑驾驶舱左右栏与顶部标题区的留白。

## 6. 成功标准
- 背景图方向稳定，不容易翻车
- 生成结果适合作为驾驶舱承载背景，而不是抢主体
