# 首页骨架生成 Skill

## 1. 作用
根据行业和页面目标，快速生成首页结构骨架。

## 2. 输入
- 行业
- 页面类型
- 展示重点

## 3. 输出
- 页面区块划分
- 区块顺序
- 每个区块职责

## 4. 输出格式建议
```md
- 顶部标题区：承载标题、时间、企业名称、全局筛选
- 左侧趋势 / 结构分析区：承载趋势和构成分析
- 中间总览核心区：承载整体表现与核心 KPI
- 右侧排行 / 目标 / 预警区：承载管理对象和风险信息
- 底部辅助明细区：承载工厂明细或辅助表格
```

## 5. 生成规则（v1）
1. 默认输出总览型首页结构。
2. 中心区必须承担“整体表现”角色。
3. 左右侧承担分析与管理对象拆解角色。
4. 底部优先承载表格或辅助信息。
5. 输出要服务于叙事逻辑，而不是仅服务于排版。

## 6. 成功标准
- 能快速给出一个稳定的首页框架
- 框架适合后续模块配置和 demo 制作
