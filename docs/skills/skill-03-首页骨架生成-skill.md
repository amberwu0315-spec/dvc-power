# 首页骨架生成 Skill

## 1. 作用
根据行业、页面目标和展示重点，快速生成一版可复用的页面结构骨架，作为后续模块配置、方案说明输出和页面草案制作的基础。

## 2. 输入
- 行业
- 页面类型
- 展示重点
- 页面用途（展示 / 汇报 / 监控，可选）
- 页面骨架方向（可选）
- 固定筛选项（可选）

## 3. 输出
- 页面区块划分
- 区块顺序
- 每个区块职责
- 骨架推荐理由

## 4. 输出格式建议
```md
- 页面骨架：顶部标题区 / 左侧趋势与结构区 / 中间总览核心区 / 右侧排行与目标区 / 底部辅助明细区
- 区块顺序：顶部标题区 → 中间总览核心区 → 左侧趋势与结构区 → 右侧排行与目标区 → 底部辅助明细区
- 区块职责：
  - 顶部标题区：承载标题、时间、企业名称、全局筛选
  - 左侧趋势与结构区：承载趋势和构成分析
  - 中间总览核心区：承载整体表现与核心 KPI
  - 右侧排行与目标区：承载管理对象、目标状态与预警信息
  - 底部辅助明细区：承载工厂明细或辅助表格
- 推荐理由：当前需求偏总览展示，适合使用中心聚焦 + 两侧拆解 + 底部补充的稳定结构，便于快速传达整体状态并兼顾管理对象说明
