# 图表与数据匹配 Skill

## 1. 作用
根据数据类型和展示目标，推荐合适的图表表达方式。

## 2. 输入
- 数据类型
- 展示目的

## 3. 输出
- 推荐图表
- 可选图表
- 不建议图表

## 4. 输出格式建议
```md
- 数据类型：趋势数据
- 展示目的：查看近 12 月变化
- 推荐图表：折线图
- 可选图表：面积折线图
- 不建议图表：环图
```

## 5. 匹配规则（v1）
- 趋势数据 → 折线图
- 构成数据 → 环图 / 堆叠柱图
- 排名数据 → 横向条形图
- 明细数据 → 表格
- 进度数据 → 进度条 / 环形进度

## 6. 成功标准
- 图表选择稳定、合理、不违和
- 输出可直接服务于模块配置和页面制作
