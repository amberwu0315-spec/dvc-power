# 行业归类 Skill

## 1. 作用
将客户行业从分散标签归并为可复用的母行业与细分行业，用于后续模板匹配。

## 2. 要解决的问题
如果行业标签不先收束，模板系统会越来越散，后续很难沉淀母版。

## 3. 输入
- 客户行业名称
- 客户业务描述（可选）

## 4. 输出
- 母行业
- 细分行业
- 推荐模板归属

## 5. 输出格式建议
```md
- 母行业：制造业
- 细分行业：汽车制造
- 推荐模板归属：制造业能碳驾驶舱
```

## 6. 归类规则（v1）
1. 优先归并为母行业，再落到细分行业。
2. 当细分行业过窄时，先按母行业推荐模板。
3. 当信息不足时，优先归类到复用性更高的母行业。
4. 当前优先支持的母行业：制造业。

## 7. 成功标准
- 行业归类稳定且可复用
- 能为模板推荐和页面编排提供统一入口
