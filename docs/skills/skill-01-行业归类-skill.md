# 行业归类 Skill

## 1. 作用
将客户行业从分散标签归并为可复用的母行业与细分行业，作为后续需求理解、页面结构建议、模块配置建议以及模板/案例参考匹配的统一入口。

## 2. 要解决的问题
如果行业标签不先收束，后续页面结构、模块推荐、模板归属和案例沉淀都会越来越散，难以形成稳定的复用逻辑。

## 3. 输入
- 客户行业名称
- 客户业务描述（可选）

## 4. 输出
- 母行业
- 细分行业
- 推荐场景归属
- 推荐模板 / 案例归属（可选）

## 5. 输出格式建议
```md
- 母行业：制造业
- 细分行业：汽车制造
- 推荐场景归属：制造业能碳总览
- 推荐模板归属：制造业能碳驾驶舱
