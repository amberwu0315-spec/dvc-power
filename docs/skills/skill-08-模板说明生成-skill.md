# 模板说明生成 Skill

## 1. 作用
自动生成模板详情页中的说明文案。

## 2. 输入
- 模板名称
- 行业
- 风格
- 页面结构
- 模块清单

## 3. 输出
- 页面定位说明
- 适用场景说明
- 模块构成说明
- 页面叙事逻辑说明
- 可延展方向说明

## 4. 输出格式建议
```md
- 页面定位：制造业能碳总览型首页模板
- 适用场景：客户提案、方向稿、demo 展示
- 模块构成：KPI、趋势、结构、排行、目标、预警、明细
- 页面叙事：总览 → 趋势 → 结构 → 排名 → 目标 → 明细
- 可延展方向：工厂详情页、目标分析页、预警页
```

## 5. 规则（v1）
1. 说明文案要解释“为什么这样设计”，而不是只描述长什么样。
2. 文案要尽量贴近模板详情页的实际展示需求。
3. 输出要帮助用户判断“适不适合当前需求”。
4. 可延展方向用于后续多页面拓展，不要求 v1 全部实现。

## 6. 成功标准
- 模板详情说明清楚、可理解、可复用
- 用户看到模板后，能知道它适合什么场景、如何继续往下做
