# 风格推荐 Skill

## 1. 作用
根据行业和使用场景，推荐适合的视觉风格方向。

## 2. 输入
- 行业
- 场景目标
- 是否偏展示 / 分析 / 汇报

## 3. 输出
- 主风格名称
- 配色建议
- 背景关键词
- 页面气质描述
- 不建议采用的风格

## 4. 输出格式建议
```md
- 主风格：深色科技能源风
- 配色：深蓝 + 青绿高亮
- 背景关键词：工业感、能源感、深色、科技、克制发光
- 页面气质：专业、稳定、清晰、展示感
- 不建议：高饱和赛博风、过重 3D 炫技风
```

## 5. 推荐规则（v1）
1. 制造业能碳场景默认推荐深色科技能源风。
2. 当需求偏展示时，可提升视觉中心感，但不提升装饰噪音。
3. 当需求偏分析时，优先清晰和秩序感，不追求炫技。
4. 当用户未给出明确偏好时，优先推荐可复用的稳妥风格。

## 6. 成功标准
- 风格建议稳定且不容易翻车
- 输出可以直接用于背景图、组件样式和页面气质判断
