# 假数据生成 Skill

## 1. 作用
生成一套可支撑 demo 的“看起来合理”的假数据。

## 2. 输入
- 行业
- 页面模块清单
- 时间范围

## 3. 输出
- KPI 数据
- 趋势数据
- 占比数据
- 排名数据
- 表格数据
- 目标完成率数据

## 4. 输出格式建议
```md
- KPI：碳排总量、综合能耗、碳强度、目标完成率
- 趋势：近 12 月碳排与能耗变化
- 构成：电力 / 燃气 / 蒸汽占比
- 排名：工厂碳排 TOP5
- 表格：工厂名称、本月碳排、能耗、状态
```

## 5. 生成规则（v1）
1. 数据之间要有逻辑关系，不能互相打架。
2. 趋势、构成、排名、表格需能相互支撑。
3. 目标完成率要与整体表现大致匹配。
4. 第一版优先追求“像真的”，不追求强业务精度。

## 6. 成功标准
- 数据能支撑完整演示
- 图表联动后不容易穿帮
- 用户无需从零手编整套 demo 数据
