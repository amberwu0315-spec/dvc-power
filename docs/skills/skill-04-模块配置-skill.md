# 模块配置 Skill

## 1. 作用
定义模块内具体显示什么标题、什么数据、什么图表类型。

## 2. 输入
- 模块名称
- 行业
- 页面目标

## 3. 输出
- 模块标题
- 模块说明
- 指标 / 数据项
- 图表类型
- 适合展示的重点内容

## 4. 输出格式建议
```md
模块：趋势分析
- 标题：月度碳排趋势
- 数据：近 12 月碳排量、同比变化
- 图表类型：折线图 / 面积折线图
- 目标：查看整体趋势变化
```

## 5. 配置规则（v1）
1. 模块标题要直接表达内容，不用过度抽象命名。
2. 数据项必须与行业和页面目标一致。
3. 图表类型必须与数据类型匹配。
4. 模块目标要说明“这一块是为了看什么”。
5. 输出优先服务于 demo 可展示性与可讲解性。

## 6. 成功标准
- 每个模块都能清晰回答“显示什么、为什么这样显示”
- 输出可直接用于页面落地
