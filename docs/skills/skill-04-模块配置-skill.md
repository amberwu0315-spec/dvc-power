# 模块配置 Skill

## 1. 作用
定义每个模块应该展示什么内容、采用什么表达方式，以及该模块在页面中承担什么信息职责，用于后续页面草案、方案说明输出和页面落地。

## 2. 输入
- 模块名称
- 行业
- 页面目标
- 展示重点（可选）
- 页面位置（可选）

## 3. 输出
- 模块标题
- 模块说明
- 指标 / 数据项
- 图表类型
- 适合展示的重点内容
- 推荐理由
- 不建议的表达方式（可选）

## 4. 输出格式建议
```md
模块：趋势分析
- 标题：月度碳排趋势
- 模块说明：展示近 12 个月整体碳排变化情况，并辅助判断波动趋势
- 数据：近 12 月碳排量、同比变化
- 图表类型：折线图 / 面积折线图
- 适合展示的重点内容：整体趋势变化、波动区间、同比变化
- 推荐理由：当前模块目标是看时间变化趋势，折线图更适合表达连续变化
- 不建议的表达方式：不建议优先使用饼图或表格作为主表达
